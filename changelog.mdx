## Stay Updated

Follow these steps to ensure you never miss an update.

<Steps>
  <Step title="Enable Notifications" icon="bell">
    Go to your account settings at `https://appsumo.com/account/notifications` and toggle on changelog emails and in-app alerts.
  </Step>
  <Step title="Subscribe to RSS" icon="rss">
    Add the changelog feed: `https://appsumo.com/changelog/rss.xml` to your reader.
  </Step>
  <Step title="Webhook Setup" icon="zap">
    Configure webhooks for automated updates.

````javascript
// Example webhook payload handler
app.post('/appsumo-webhook', (req, res) => {
  const { event, data } = req.body;
  if (event === 'new_release') {
    console.log(`New version: ${data.version}`);
  }
  res.status(200).send('OK');
});
````

  </Step>
</Steps>
