---
title: Cannot Access Purchased Tool
description: Quick steps if you're unable to access your AppSumo tool.
---

## Symptoms

- Tool login fails
- Access link not working
- Redemption code not accepted

## Quick Fix

<Steps>
  <Step title="Check Redemption">  
    Was the code redeemed? Try copying and pasting the code again.  
  </Step>
  <Step title="Email Used">  
    Make sure you use the same email as your AppSumo account.  
  </Step>
  <Step title="Reset Password">  
    Use the "Forgot Password" link at the tool's site if needed.  
  </Step>
  <Step title="Contact Support">  
    If the issue persists, email support@appsumo.com with your order details.  
  </Step>
</Steps>
